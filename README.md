# Linear Regression Lab

**Aplicação educacional interativa para ensino de regressão linear e mínimos quadrados**, desenvolvida para cursos da área da saúde.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19650334.svg)](https://doi.org/10.5281/zenodo.19650334)

🔗 **[Acessar o app](https://henriquealvarenga.com/linear-regression-lab/)**

---

## Sobre

O Linear Regression Lab é um jogo educacional com 7 rounds de dificuldade crescente. Em cada round, o aluno ajusta manualmente uma reta de regressão a um dataset clínico fictício, competindo contra o relógio. Entre os rounds, perguntas conceituais reforçam o aprendizado.

O objetivo é desenvolver intuição visual sobre o que significa "melhor ajuste" e por que o método dos mínimos quadrados (OLS) é a solução ótima.

## Funcionalidades

- 7 rounds com datasets clínicos (sono, exercício, IMC, vitamina D, etc.)
- Ajuste manual da reta com drag — inclinação e intercepto
- Pontuação por qualidade do ajuste + bônus de velocidade (máx. 1050 pts)
- Quiz conceitual entre rounds (24 perguntas com feedback explicativo)
- Heatmap da paisagem do RSS (espaço de parâmetros β₀ × β₁)
- Easter egg: 7 curiosidades sobre o número 7
